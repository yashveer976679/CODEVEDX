# 👋 Welcome

This repository contains my **AI & Machine Learning Internship Projects**, built using **Python, Flask, Machine Learning, Natural Language Processing, and Scikit-learn**.

These projects demonstrate practical implementations of AI concepts including prediction systems, recommendation engines, NLP applications, and intelligent chatbots.

# 📂 Projects

| Project | Description | Technologies |
|---------|-------------|--------------|
| 📊 Utility Usage Prediction | Predicts utility consumption using Machine Learning. | Python, Pandas, Scikit-learn |

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yashveer976679/CODEVEDX.git
```

Go to the repository

```bash
cd CODEVEDX
```

Open any project folder.

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```

or

```bash
python main.py
```

depending on the project.
