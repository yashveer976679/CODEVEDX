# 🎬 CineAI - Smart Movie Recommendation System

A Flask-based Movie Recommendation System that suggests similar movies using **Machine Learning** and **Content-Based Filtering**. The system analyzes movie genres, keywords, and overviews to recommend movies with similar content.

---

## 📌 Project Overview

This project uses **TF-IDF (Term Frequency-Inverse Document Frequency)** and **Cosine Similarity** to recommend movies based on a user's selected movie. It features a modern web interface built with Flask and demonstrates the fundamentals of recommendation systems.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/CODEVEDX.git
```

Go to project folder

```bash
cd Project-5-Movie-Recommendation-System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```

## 🎮 How to Use

1. Open the application.
2. Enter a movie name (e.g., **Iron Man**, **Avatar**, **Interstellar**).
3. Click **Recommend**.
4. View similar movie recommendations with:
   - Movie Title
   - Rating
   - Release Year
   - Genres
   - Similarity Score
   - Overview
