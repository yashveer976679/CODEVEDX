# AI Fake News Detection Tool

## Description
An NLP-based Machine Learning application that classifies news articles as Fake or Real using TF-IDF Vectorization and Logistic Regression.

## Features
- Detect Fake News
- Confidence Score
- Saved Machine Learning Model
- NLP Text Processing
- Kaggle Dataset

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib
- TF-IDF
- Logistic Regression

## Dataset
Kaggle Fake and Real News Dataset

## Run

pip install -r requirements.txt

python train_model.py

python main.py
