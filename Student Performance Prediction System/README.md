# Student Performance Prediction System

## Description
A Machine Learning project that predicts a student's final marks based on attendance, study hours, and internal marks using Linear Regression.

## Features
- Add Student Data
- View Student Data
- Predict Final Marks
- Data Visualization (Charts)
- Model Accuracy
- CSV File Handling
- Exception Handling

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Structure

Student_Performance_Prediction/
│
├── main.py

├── README.md

pip install -r requirements.txt
